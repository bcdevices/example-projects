# Example Projects

A collection of KiCad hardware design projects, well mostly KiCad.
Confiential files should not be placed here!

## Structure

Each project lives in its own folder:

```
example-projects/
├── board-name-1/
│   ├── board-name-1.kicad_pro
│   ├── board-name-1.kicad_pcb
│   ├── board-name-1.kicad_sch
│   └── bom.csv
└── board-name-2/
    └── ...
```

## Files

| Extension | Description |
|---|---|
| `.kicad_pro` | KiCad project file |
| `.kicad_pcb` | PCB layout |
| `.kicad_sch` | Schematic |
| `.csv` | Bill of materials |

## Requirements

- [KiCad](https://www.kicad.org) 7.0 or later
